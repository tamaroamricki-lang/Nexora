NOVA TV 2.0 - دليل التشغيل

الملفات: index.html style.css app.js player.js channels.json
(channels.json اختياري: قنوات تظهر لكل مستخدمي التطبيق. أما القنوات التي تضيفها من داخل التطبيق فتُحفظ على جهازك.)

1) الرفع إلى GitHub Pages (من الهاتف)
1. فك ضغط ZIP على هاتفك.
2. في github.com: New repository > اسم (مثل nova-tv) > Public > Create.
3. افتح المتصفح بوضع "موقع سطح المكتب" > uploading an existing file > اختر الملفات الخمسة > Commit changes.
4. Settings > Pages > Deploy from a branch > main و /(root) > Save.
5. بعد 1-3 دقائق يظهر الرابط: https://اسم-المستخدم.github.io/nova-tv/
(عند رفع نسخة جديدة استبدل الملفات الخمسة كلها.)

2) AppCreator24
لم أتحقق من واجهته الحالية؛ قد تختلف الأسماء. أضف قسماً من نوع Web والصق الرابط، وفعّل ملء الشاشة وتشغيل الجافاسكربت والفيديو إن وُجدت الخيارات. اترك الاتجاه تلقائياً.

3) إضافة القنوات (داخل التطبيق)
اضغط + أعلى الشاشة:
- "رابط شامل": رابط قائمة M3U أو JSON فيها قنوات كثيرة، توزّعها على التصنيفات تلقائياً.
- لكل تصنيف أيقونة وزر +: رابط قائمة لهذا التصنيف، أو "قناة واحدة" (اسم + رابط بث).
- تُحدَّث القوائم تلقائياً كل 12 ساعة (تقليلاً للبيانات)، أو يدوياً من الإعدادات.
- ملاحظة: بعض المواقع تمنع المتصفح من قراءة القائمة (CORS) فتظهر رسالة. روابط GitHub (raw.githubusercontent.com و github.io) تعمل عادةً.
أمثلة معروفة لقوائم عامة (تحقق بنفسك من حقوق البث): https://iptv-org.github.io/iptv/countries/ma.m3u (المغرب) و https://iptv-org.github.io/iptv/languages/ara.m3u (العربية) و https://iptv-org.github.io/iptv/categories/news.m3u (الأخبار).

4) كيف يتعامل التطبيق مع القنوات الكثيرة والمعطلة
- يعرض القنوات دفعات صغيرة أثناء التمرير، فلا يعلق مع آلاف القنوات.
- يفحص القنوات الظاهرة فقط فحصاً خفيفاً (بضعة بايتات لكل قناة) ويخفي التي لا تستجيب (يمكن إيقافه من الإعدادات).
- عند التشغيل يجرّب عدة طرق تلقائياً (HLS.js ثم المشغّل الأصلي، وترقية http إلى https، والرابط الاحتياطي).
- توفير البيانات: أدنى جودة وبلا شعارات (من الإعدادات أو زر "توفير" في المشغّل).

5) المشغّل
- في الوضع العمودي: الفيديو بمقاس 16:9 في الأعلى وتحته القنوات التالية.
- زر ملء الشاشة أو تدوير الهاتف: يتحول إلى الوضع الأفقي الكامل. إن لم يسمح WebView بقفل الاتجاه يدوّر التطبيق الشاشة بنفسه.

6) حدود لا يمكن تجاوزها
- قنوات DRM أو المقيّدة بالمنطقة أو التي تمنع CORS أو روابط http على منفذ غير قياسي، أو بث TS خام: لن تعمل داخل المتصفح/WebView مهما كان الكود. هذا سبب فشل نسبة كبيرة من قوائم IPTV العامة.
- الفحص الخفيف يكشف الخوادم المتوقفة فقط، ولا يضمن أن القناة ستعمل. حالة "مباشر" تظهر بعد نجاح التشغيل فعلاً.
- لوحة إدارة بخادم وقاعدة بيانات لم تُبنَ؛ الإدارة عبر channels.json والإضافة من التطبيق.
